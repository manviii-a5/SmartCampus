# SmartCampus

## Smart Campus: Intelligent Campus Navigation and Management System

### Project Overview
SmartCampus is a terminal-based intelligent campus navigation and management system that provides a digital representation of a campus and helps manage navigation, resources, bookings, and emergency situations.

The project integrates **Data Structures and Algorithms in C** with **Object-Oriented Programming in C++**. Campus locations are represented as a weighted graph, allowing shortest-path navigation using Dijkstra's algorithm.

### Objectives
- Develop a modular campus management system.
- Implement important Data Structures and Algorithms in C.
- Apply C++ OOP concepts to model campus entities.
- Provide graph-based campus navigation.
- Manage bookings, resources, and emergency requests.
- Integrate C and C++ components into one system.

### Technology Stack
- C
- C++
- Data Structures and Algorithms
- Object-Oriented Programming
- Graph Algorithms
- Dijkstra's Algorithm
- BFS and DFS
- File Handling
